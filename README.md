# Detecting-Cryptocurrency-Wallet-Fraud-Using-Supervised-and-Unsupervised-Machine-Learning
WQD7025 Data Science Research Project

Dataset source: https://github.com/eltontay/Ethereum-Fraud-Detection

Dataset used: address_data_combined_ts.csv

Objectives:

RO1: To identify the characteristics of fraudulent cryptocurrency wallets based on transaction features. 

RO2: To apply and compare the supervised and unsupervised machine learning models for detecting cryptocurrency wallet fraud using labeled and unlabeled data.

RO3: To analyze and evaluate the performance and interpretability of both models for cryptocurrency wallet fraud detection using evaluation metrics along with SHAP-based explanations for supervised models.
